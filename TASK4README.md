# Online Examination System 📝

## 📌 Project Overview

The Online Examination System is a Java-based application designed to conduct examinations digitally. It allows users to log in, attend an online examination, answer multiple-choice questions, and view their results.

This project was developed as part of my internship to practice Java programming, object-oriented programming, user input handling, and application logic.

## ✨ Features

- User login and authentication
- Online multiple-choice examination
- Question and option display
- Answer selection
- Automatic score calculation
- Timer-based examination
- Automatic submission when time expires
- Result display after examination
- Simple and user-friendly interface

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Java Scanner
- ArrayList
- VS Code

## ⚙️ How It Works

1. The user starts the application.
2. The user logs in using valid credentials.
3. The examination begins.
4. Multiple-choice questions are displayed.
5. The user selects answers for each question.
6. The system keeps track of the selected answers.
7. The examination is automatically submitted when the timer ends or when the user completes the test.
8. The system calculates the score.
9. The final result is displayed to the user.

## ▶️ How to Run

1. Install Java JDK on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java files:
